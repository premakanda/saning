## 7. Маршруты и навигация

- `/` — Главная.
- `/services/` — Услуги.
- `/services/heating/` — Монтаж систем отопления.
- `/services/water-supply/` — Монтаж систем водоснабжения.
- `/services/sewerage/` — Монтаж канализации.
- `/services/sanitary-installation/` — Установка сантехнических приборов.
- `/articles/` — Статьи.
- `/articles/:slug/` — Статья из YAML, с SSG и отдельным HTML на каждый slug.
- `/contacts/` — Контакты.
- `/privacy/` — Политика конфиденциальности, если публикуется.

Добавить видимые **хлебные крошки** на вложенных страницах: например, «Главная → Услуги → Монтаж систем отопления». Ссылками должны быть все элементы, кроме текущего; текущая страница помечена `aria-current="page"`. Реализовать соответствующую достоверную разметку `BreadcrumbList` JSON-LD. На главной хлебные крошки не нужны.

## 8. Требования к реализации

- React + TypeScript + Vite, CSS Modules, Mobile First, переключение светлой и тёмной темы.
- Статическая генерация индексируемого HTML для каждой страницы и статьи. Клиентский роутинг без SSG недостаточен для поставленной SEO-задачи.
- Единый компонент `SiteHeader`, `SiteFooter`, `Breadcrumbs`; иконки с доступными названиями и понятными зонами нажатия.
- Данные услуг вынести в типизированную структуру, чтобы карточки и страницы использовали одни и те же данные. YAML применяется прежде всего для статей.
- Понятные заголовки, уникальные title/description, canonical, sitemap.xml, внутренние ссылки. Геотаргетинг только Минск и Минская область, Google — основной приоритет, Яндекс — дополнительный.
- Контраст и фокус WCAG 2.2 AA, адаптивные изображения и внятная мобильная навигация.
- Не запускать ненастроенные ссылки мессенджеров и не выдавать демонстрационные формы за работающие.
- Не добавлять каталог, корзину, личный кабинет, backend и лишние страницы.
