# АкваЛайнПрофи — контент и изображения для Codex

Распакуйте ZIP в корень уже существующего репозитория. Затем отправьте Codex:

«Изучи AGENTS.md и CONTENT_AND_MEDIA.md. Реализуй согласованные страницы и тексты, используй изображения из public/images и иконки из src/assets/icons. Не пересоздавай проект и не добавляй неподтверждённые услуги. Сначала сообщи, какие существующие файлы потребуется изменить».

В пакете:

- CONTENT_AND_MEDIA.md — все тексты и задачи по страницам;
- IMAGE_MANIFEST.json — список вложенных изображений;
- public/images/** — реальные оптимизированные изображения WebP;
- src/assets/icons/** — SVG-иконки для карточек.

Внимание: картинки являются AI-иллюстрациями, а не доказательством выполненных компанией работ. Для канализации и установки сантехники предметных изображений нет — используйте подготовленные SVG-иконки.
