## Технические требования

- На страницах `/services/sewerage/` и `/services/sanitary-installation/` использовать соответствующие фото в тематических секциях; не смешивать категории.
- Для SEO сохранять смысловой HTML-текст рядом с картинками и задавать `alt` по `IMAGE_MANIFEST.json`.
- Изображения имеют исходное соотношение сторон 4:3 (1448×1086). Резервировать пространство через `width`, `height` или `aspect-ratio`.
- Для некритичных изображений применять `loading="lazy"`; первое изображение в Hero при необходимости грузить приоритетно.
- Mobile First: адаптивные размеры, `max-width: 100%`, `object-fit`, никакой горизонтальной прокрутки.
- Карточки четырёх направлений на главной и `/services/` сохраняют SVG-иконки; изображения можно использовать как иллюстрации на подробных страницах, не превращая список услуг в фотогалерею.
- Не считать AI-визуализации выполненными работами. Они художественные и могут содержать технические неточности.
- Не создавать новые услуги по изображению: в особенности монтаж септиков/ёмкостей показывать как услугу только после подтверждения владельцем.
