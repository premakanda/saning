# АкваЛайнПрофи — пакет из 8 статей и обложек

## Что внутри

- `src/content/articles/*.yaml` — 8 самостоятельных статей на русском языке, соответствующих схеме `AGENTS.md`.
- `public/images/articles/*.webp` — 8 тематических иллюстраций.
- `ARTICLE_MANIFEST.json` — обзор тем, slug и путей к обложкам.

## Как подключить

1. Распакуй ZIP в корень существующего Vite/React-проекта, сохранив структуру директорий. Не заменяй `AGENTS.md` и существующие файлы приложения.
2. Изучи `AGENTS.md` и существующий генератор статей. Если схема YAML в коде отличается, адаптируй импорт/валидацию к подтверждённым полям (`title`, `slug`, `description`, `publishedAt`, `published`, `category`, `coverImage`, `coverAlt`, `content`), не ломая уже опубликованные материалы.
3. Обнаруживай новые `.yaml` автоматически. Для каждой опубликованной статьи собирай статический HTML по маршруту `/articles/<slug>/` (или существующему утвержденному шаблону). Реализуй главную страницу списка `/articles/` с карточками, картинками и краткими описаниями.
4. Картинки уже оптимизированы в WebP. Не импортируй их по неверным путям: они доступны как `/images/articles/<slug>.webp`.
5. Для карточек используй `coverImage`, для `<img alt>` — `coverAlt`, в статье выводи один H1 из `title`, не дублируй его в Markdown-контенте. Добавь SEO `<title>`, description, canonical, Open Graph, `Article` JSON-LD при наличии корректных данных издателя, BreadcrumbList и sitemap.
6. Ссылки на соответствующие услуги добавляй по смыслу: отопление → `/services/heating/`, вода → `/services/water-supply/`, канализация → `/services/sewerage/` (проверь реальные маршруты проекта). Не вставляй слепо ссылки на несуществующие страницы.
7. Обложки созданы ИИ как художественные иллюстрации. Их нельзя подавать как реальные работы команды или точные монтажные схемы. Это не проекты для инженерных расчётов.
8. Проверь схему, отсутствие дублей slug, формирование маршрутов, sitemap, корректное отображение на мобильных, обе темы, оптимизацию и production build. Сообщи об ошибках, не заявляй о выполнении непроведённых проверок.

## Редакционные пометки

- Дата `2026-11-07` — дата подготовки файлов. Перед публикацией при необходимости установи фактическую дату выхода; не подменяй `updatedAt` датой сборки.
- Тексты вводные и не заменяют проект, инструкции производителя или соблюдение действующих норм Беларуси. Газовые подключения и ввод оборудования выполняются только допущенными специалистами.
- Дополнительные факты о компании, опыте, ценах и гарантиях не придумывать.
- В идеале просмотреть каждую статью на точность и соответствие реально оказываемым услугам перед индексацией.
