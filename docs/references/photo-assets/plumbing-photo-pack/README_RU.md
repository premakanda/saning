# Фотографии для сайта сантехнических услуг

Папки подготовлены под **Vite + React**, фотографии должны лежать в `public/images/`. Это удобнее, чем `src/assets`, когда адреса картинок будут прописаны в YAML-статьях и данных услуг.

**Важно:** в архиве пока находятся структура, инструкции, ссылки и скрипт загрузки. Самих JPG внутри нет: загрузка файлов из фотостоков в текущем окружении недоступна.

## Что делать

1. Распакуй этот ZIP.
2. Если есть Python 3 и интернет, выполни `python scripts/download_photos.py` в распакованной папке. Скрипт скачает пять файлов по четырём Pexels-фотографиям.
3. Если Python нет или загрузка не проходит, открывай ссылки из `PHOTO_ASSETS.md` и сохраняй фотографии вручную под указанными названиями.
4. Скопируй папку `public/images/` в корень своего Vite-проекта.
5. `PHOTO_ASSETS.md` и `photo-manifest.json` положи в корень репозитория. Скрипт можно оставить в `scripts/`, но не обязательно.

Не добавляй в продакшен пустые имитации JPG. Изображения тёплого пола, котельной и остальных ещё не закрытых категорий продолжаем искать.
