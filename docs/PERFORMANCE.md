Оценки Lighthouse могут меняться между запусками и зависят от среды.

## Что изменено

- Внутренние ссылки используют React Router Link, сохраняя настоящие `a href`
  в статическом HTML и работу без JavaScript.
- Место под полосу прокрутки зарезервировано через `scrollbar-gutter: stable`.
  Переходы между четырьмя пунктами меню больше не перезагружают документ;
  горизонтальная позиция хедера постоянна вместо прежнего смещения 7,5 px.
- Хедер закреплён CSS sticky без обработчика scroll. Якоря учитывают его высоту,
  ссылка пропуска навигации остаётся поверх него.
- Исходная иллюстрация сохранена. Для сайта подготовлены WebP 1672 px / 127 КБ
  и 960 px / 56 КБ вместо PNG / 1,8 МБ, с responsive srcset.
- Добавлены preload локального Manrope и SVG favicon утверждённой капли.
- Хешированные файлы `/assets/*` получают годовой immutable cache в Cloudflare
  `_headers`. HTML не получает это правило.
- Локальный сервер сборки отдаёт корректные MIME-типы и gzip для текстовых
  ресурсов; это приближает измерение к доставке статических файлов на хостинге.

Ненулевые диагностические рекомендации Lighthouse по неиспользуемому на первом
экране JavaScript и блокирующим CSS остаются; 100 баллов не означает отсутствие
всех рекомендаций и не заменяет ручную проверку доступности.

## Проверки и повторный запуск

Проверены девять маршрутов в шести ширинах и двух темах: 108 сочетаний,
закрепление хедера, мобильное меню, якорь услуг, сохранение темы и модальная форма.
Линтер, TypeScript, пять тестов и статическая сборка проходят. Форматирование
приложения проверено отдельно; общий `npm run check` дополнительно сообщает о
форматировании трёх файлов добавленного `AquaLineProfi_Codex_Content_Pack`.
Исходные файлы этого контент-пакета не изменены.

```sh
npm run build:local
npm run preview
npx --yes lighthouse http://localhost:4173/ --view
```

Для десктопа добавить `--preset=desktop`. Подробные HTML/JSON-отчёты и браузерные
замеры сохранены локально в `.impeccable/review/performance/` и исключены из Git.
