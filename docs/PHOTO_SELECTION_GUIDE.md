# PHOTO_SELECTION_GUIDE.md — временный набор фотографий

Статус: согласовано для прототипа, 5 ноября 2026. React + TypeScript + Vite, CSS Modules, mobile first.

## Текущее решение

Использовать уже найденные стоковые фотографии-кандидаты из списка ниже **и продолжать поиск**, если для конкретной услуги или блока не хватает подходящих изображений. **Тёплый пол, укладка/раскладка труб, монтажные схемы, котельные, радиаторы и сантехническое оборудование остаются в фотоплане.** Не удалять услуги или иллюстрации этих направлений без отдельного указания владельца. Каждое найденное фото — кандидат, а не автоматически одобренный материал для публикации.

Пока не создавать раздел с якобы собственными выполненными работами. Не представлять стоковые снимки как фотографии наших мастеров или объектов. Реальные фотографии будут добавлены позже.

## Правила размещения

- **Hero:** подобрать подходящий широкий кадр из найденных или новых кандидатов, если он хорошо кадрируется и не вводит в заблуждение; до выбора использовать аккуратную временную композицию без обманчивого фото.
- **Карточки услуг:** преимущественно подготовленные SVG-иконки; изображения — лишь в тех карточках, где есть подходящий снимок.
- **Страницы услуг:** для каждой услуги искать действительно относящиеся к работе стоковые фото; пока снимок не найден и не проверен, не вставлять случайную фотографию или пустую заглушку.
- **Статьи:** подбирать соответствующие теме обложки по мере подготовки публикаций; при отсутствии подтверждённой фотографии статья может временно оставаться без обложки.
- **Наши работы:** блок скрыть до появления реальных подтверждённых фотографий.
- **Тёплый пол, раскладка труб, монтажные схемы и дополнительные фото:** **сохранять в плане и продолжать подбор**. Схемы и иллюстрации использовать только при наличии прав на использование; чужие схемы не копировать автоматически.

## Требования к коду и SEO

1. Копировать фотографии в репозиторий только после проверки лицензии конкретного файла. Не делать hotlink на сторонние сайты в production.
2. Подготовить оптимизированные WebP/AVIF и подходящие размеры. Не искажать пропорции.
3. Для hero предусмотреть корректные размеры и приоритет загрузки; изображения ниже первого экрана загружать лениво.
4. Использовать смысловой `alt`; декоративные снимки — `alt=""`. Не выдавать стоки за реальные работы компании.
5. Проверять мобильное кадрирование (mobile first) и контраст в светлой/тёмной теме.
6. Продолжать подбор новых изображений для недостающих тем. До включения в production проверять лицензию, релевантность и качество; спорные варианты согласовывать с владельцем.

## Для Codex

Считай этот документ актуальным планом по фотоматериалам. **Не исключай** тёплый пол, укладку/раскладку труб, монтажные схемы, котельные и другие услуги. Используй подходящие подтверждённые стоковые фотографии; **там, где фотографий не хватает, продолжай поиск и фиксируй кандидатов и источники**. SVG-иконки применяй для интерфейсных карточек, не вместо полноценного фотоплана. Не публикуй изображения без проверки прав и не выдавай стоки за работы компании.
